# גמרא למתחילים בניחותא — שלב 01

קובץ זה הוא שלד אתר סטטי ראשוני לפי שלב 1 בתכנית העבודה.

## מה נבנה כאן

- נתיב עברי: `/he/`
- נתיב אנגלי שמור לעתיד: `/en/`
- תבנית אתר כללית: כותרת עליונה, תוכן, ניווט תחתון ופוטר
- תפריט ראשי: בית, שיעורים, מפת מושגים, איך לומדים כאן, אודות
- דף סדרה ראשוני
- דף שיעור 001 מלא
- תיקיית תוכן לשיעורים בפורמט Markdown
- תיקיית נכסים לתמונות הדף: `assets/daf/`
- מילון ארמי ומילון מושגים ראשוניים כקובצי JSON

## איך מפעילים מקומית

פותחים את התיקייה בשרת סטטי. לדוגמה:

```bash
python -m http.server 8000
```

ואז נכנסים בדפדפן:

```text
http://localhost:8000/he/
```

## תמונת הדף לשיעור 001

כדי שתמונת הדף תופיע אוטומטית במקטע "פוגשים את הדף", יש להניח אחד מן הקבצים הבאים:

```text
assets/daf/001.webp
assets/daf/001.png
```

ה־ALT כבר מוגדר בדף השיעור.

## הערה

זהו שלב 1 בלבד: שלד האתר והמבנה הבסיסי. בשלב הבא נכון לעבור לשפה חזותית וקריאות, ואז למערכת תוכן לשיעורים.
